# Nissi Super Stores

Nissi Super Stores – Grocery Store Management, Customer Ordering & Doorstep Delivery Platform

## About The Project

This is a full-featured web application for Nissi Super Stores built using React and Vite. It provides an intuitive interface for online grocery browsing, shopping cart management, checkout, order tracking, and administrative controls.

## Features

- **Interactive Storefront**: Browse groceries, utility services, and special offers.
- **Cart & Checkout**: Streamlined checkout process with doorstep delivery scheduling.
- **Order Tracking**: Real-time tracking interface for customer orders.
- **Admin & Delivery Dashboard**: Operations interface for managing products, orders, and delivery assignments.

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
